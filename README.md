# Three Card Poker

## Project Overview

Three Card Poker is a JavaFX application that simulates a poker game between two players and a computer dealer. Players can place wagers, receive cards, choose to Play or Fold, and view their round results and total winnings.

## Technical Skills

- Java
- JavaFX
- FXML and CSS
- Maven
- JUnit
- Figma
- Object-Oriented Programming

## Design and Development

I first created wireframes using Figma to plan the layout and navigation of the application. The application consists of three main screens: Welcome, Game Play, and Results.

I then implemented the application using JavaFX and separated the game logic from the graphical user interface to make the program easier to maintain and test.

## Challenges and Testing

During usability testing, I received feedback regarding unnecessary scrolling, spacing between controls, and unclear wagering instructions.

I improved the design by reducing the screen sizes and simplifying the player controls.

I also used JUnit to test hand rankings, payout calculations, deck initialization, and card dealing.
